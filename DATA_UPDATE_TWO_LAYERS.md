# Updated layers — 2026-09-24

The platform now uses the newly supplied versions of:

- `Agricultural_Field.geojson` — 376 polygon features
- `Farm_Land_Cover.geojson` — 69 polygon features

Both layers are now enabled in the operational layer configuration, are available in the map Layers control, can be clicked for attribute information, and are included in the map-feature legend.

## Agricultural Field fields
`Field_ID`, `Governorat`, `Wilayat`, `Plant_Type`, `Plant_Ty_1`, `Tree_Count`, `Survey_Dat`, `Latitude`, `Longitude`, `Shape_Area`.

## Farm Land Cover fields
`Farm_ID`, `Land_Cover`, `Land_Cov_1`, `Governorat`, `Wilayat`, `Latitude`, `Longitude`, `Shape_Area`.
